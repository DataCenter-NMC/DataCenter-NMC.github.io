# Data Center, Northern Medical Center website

This repository contains the public website for **Data Center, Northern Medical Center**.

Once this repository is published as `DataCenter-NMC/DataCenter-NMC.github.io`, GitHub Pages can serve it at:

<https://datacenter-nmc.github.io/>

The site is intentionally static and does not collect user information or personal health information.

## Search indexing

The canonical production URL is `https://datacenter-nmc.github.io/`. The repository includes a
root-level `robots.txt` and `sitemap.xml`, along with Organization, WebSite, WebPage, Person, and
publication structured data in `index.html`.

After a significant content update, update the `dateModified` value in `index.html` and the
matching `lastmod` value in `sitemap.xml`. Once the site is deployed, verify the domain in Google
Search Console and Bing Webmaster Tools and submit `https://datacenter-nmc.github.io/sitemap.xml`.
An editorially appropriate link from the official Northern Medical Center website will also help
search engines confirm the Data Center's institutional relationship.
